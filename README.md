# iso2nsp

**iso2nsp** — автономная утилита и графическое приложение для конвертации управляющих программ ЧПУ (G-код ISO от CAM-систем Lantek / плазменного и лазерного раскроя) в проекты раскроя **CypNest / FSCUT / RayTools (`.nsp`)**.

Приложение поставляется как в виде исходного кода на Python, так и в виде **портативного исполняемого файла `iso2nsp.exe`**, который запускается **на любом компьютере с Windows без прав администратора и без необходимости устанавливать Python**.

---

## Возможности

- **Портативность (Zero-Install):** единый `.exe` файл без зависимостей, не требует прав администратора и работает сразу после скачивания.
- **Интерактивный 2D-предпросмотр:**
  - Масштабирование колесиком мыши (Zoom) и плавное перемещение листа (Pan);
  - Отображение контура листа, координатной сетки, габаритов в миллиметрах;
  - Цветовая дифференциация: контуры деталей (зеленый), внутренние отверстия `layer="I"` (синий), сквозные технологические резы делового остатка (красный).
- **Интерактивная таблица деталей:**
  - Список всех найденных на листе деталей с их точными габаритами ($W \times H$) и количеством;
  - **Мгновенная подсветка:** клик по строке в таблице подсвечивает все экземпляры выбранной детали на листе ярким золотисто-желтым цветом;
  - **Быстрое переименование:** возможность в 1 клик присвоить деталям понятные имена (например, `А1184 К-1-3`), которые будут экспортированы в проект CypNest.
- **Управление технологической обрезкой листа (Cutoff lines):**
  - По умолчанию линии гильотинного отреза / обрезки делового остатка больше не переносятся в проект CypNest `.nsp` (в файл попадают только готовые чистые детали);
  - Быстрое переключение кнопкой `✂ Убрать обрезку` / `✂ Включить обрезку` (с опцией «Ко всем листам» для группового применения);
  - На 2D-холсте отключенная обрезка наглядно отображается приглушенным серым пунктиром с пометкой `✂ Обрезка (откл.)`, а включенная — сплошной ярко-красной линией.
- **Автоматическая привязка отчетов Lantek CAM (PDF):**
  - Поддержка совместного выбора файлов УП (`.iso`, `.cnc`) и отчетов раскроя (`.pdf`) прямо в одном диалоговом окне «+ Добавить файлы...»;
  - Отдельная кнопка «📑 Подгрузить отчеты Lantek (PDF)» для привязки отчетов к уже открытым листам проекта;
  - Автоматическое сопоставление отчетов с листами УП по имени программы / цифровому префиксу файла;
  - Автоматическое присвоение официальных заводских имен деталям из спецификации Lantek (по габаритам $W \times H$ и количеству);
  - Автоматическое выставление тиража листов (числа повторов) и наименования заказа из шапки отчета.
- **Производственные PDF-отчёты (стиль Lantek CAM):**
  - Экспорт официальных технологических карт раскроя в формате А4 (1 в 1 по стандарту Lantek CAM);
  - Векторный масштабированный чертёж листа с контурами деталей, отверстиями и номерами деталей внутри них (`#1`, `#2`, ...);
  - Автоматическая штриховка зон делового отхода / остатка листа (`REMNANT`) диагональными линиями под углом 45° по линии реза гильотины;
  - Сводная карточка параметров: Заказ, Лист, Ссылка, Дата/Время, Станок/ЧПУ, Тираж, Габариты ($W \times H$), Толщина, Марка металла, Расчетный вес листа (кг), Процент полезного использования металла (% Util.);
  - Полная таблица спецификации деталей: порядковый номер (#), наименование/артикул, количество на листе, суммарное количество во всем заказе с учетом тиража, вес (кг), габаритные размеры ($W \times H$);
  - Поддержка экспорта как одиночного текущего листа, так и полного многостраничного отчета по всем листам заказа в единый PDF-файл;
  - Мгновенное открытие готового отчета в системном просмотрщике PDF сразу после экспорта.
- **Многолистовые проекты (Multi-Sheet Jobs):**
  - Пакетная загрузка группы файлов раскроя (`+ Добавить файлы...` с мультивыбором `*.iso`, `*.cnc`, `*.nc`, `*.tap`, `*.txt`, `*.pdf`);
  - Автоматическое определение имени заказа (Job Name) по общему префиксу файлов (например, `1849 FE6`);
  - Таблица листов с индивидуальным тиражом (количеством повторов) каждого листа;
  - Мгновенное переключение активного листа в 2D-предпросмотре и спецификации деталей;
  - Опция «Применить ко всем листам» для группового поворота, смены осей или отражения;
  - Единая глобальная дедупликация деталей по всем листам заказа с суммированием тиража (`totalnum` / `partProcessNum`);
  - Экспорт в единый XML `.nsp` со всеми узлами `<PlateNode>` и общей библиотекой `<CutPieceNode>`.
- **Трансформации раскроя:**
  - Автоматическая смена станочных осей на оси листа ($X \leftrightarrow Y$) и зеркалирование по $Y$ для точного соответствия чертежам Lantek (раскрой сверху листа);
  - Ручной доворот на $\pm 90^\circ$ и $180^\circ$;
  - Отражение по горизонтали (Flip X) и вертикали (Flip Y) с автоматической математической инверсией направления дуг ($G02 \leftrightarrow G03$ и знака bulge);
  - Прижатие к углу (отступ 10 мм) или центрирование на листе.
- **Интеллектуальная дедупликация (Rotated Deduplication):**
  - Автоматическое распознавание одинаковых деталей, повернутых на $90^\circ$, $180^\circ$ или $270^\circ$;
  - Группировка повернутых копий под единым мастер-шаблоном `<CutPieceNode>` с указанием угла вставки `PartInsertAngles`;
  - Автоопределение марки материала (`FE`, `SS`, `AL`) и толщины из имени файла или заголовка.
- **Сохранение точной хронологии резки (Toolpath Preservation):**
  - Экспорт деталей и внутренних отверстий в проект `.nsp` в строгой хронологической последовательности резки из исходного ISO-файла (без случайных прыжков между углами листа при симуляции).
- **Консольная версия (CLI):** возможность автоматической пакетной обработки в скриптах (`python iso2nsp.py sheet1.iso sheet2.iso -o job.nsp --repeats 2 1 --pdf`).

## Запуск приложения

### Вариант 1. Запуск через готовый `iso2nsp.exe` (Рекомендуется)
1. Скачайте файл `iso2nsp.exe` из репозитория.
2. Запустите двойным кликом. Установка не требуется, права администратора не нужны.

### Вариант 2. Запуск из исходного кода Python
Требуется Python 3.8+ (используются только стандартные модули):
```bash
# Графический интерфейс
python iso2nsp_gui.py

# Консольный режим (CLI)
python iso2nsp.py input.iso -o output.nsp
```

## Консольный интерфейс (CLI)

```bash
python iso2nsp.py input.iso -o output.nsp [параметры]
```

### Параметры командной строки:
- `-o, --output` — путь к выходному файлу `.nsp` (по умолчанию: `{имя}.nsp`);
- `--job-name` — имя заказа / проекта;
- `--repeats` — тираж для каждого входного листа (например, `--repeats 1 2 1`);
- `--pdf [путь]` — сформировать производственный технологический отчет в формате PDF (стиль Lantek CAM);
- `--orientation {auto, vertical, horizontal}` — режим ориентации листа (по умолчанию: `auto`);
- `--swap-axes` — принудительно поменять оси $X$ и $Y$ местами;
- `--rotate {0, 90, 180, 270}` — доворот карты раскроя;
- `--flip-x` — отразить по горизонтали;
- `--flip-y` — отразить по вертикали;
- `--sheet-size WxH` — переопределить габариты листа (например, `1500x3000`);
- `--thickness T` — толщина листа в мм;
- `--material M` — марка материала (по умолчанию: `SUS`).

## Сборка `.exe` файла из исходников

Если вы хотите самостоятельно пересобрать бинарный файл:
```bash
pip install pyinstaller reportlab pypdf
pyinstaller --onefile --noconsole --name iso2nsp iso2nsp_gui.py
```
Или при использовании менеджера пакетов `uv`:
```bash
uvx --with reportlab --with pypdf pyinstaller --onefile --noconsole --name iso2nsp iso2nsp_gui.py
```
Собранный файл появится в текущей папке.
